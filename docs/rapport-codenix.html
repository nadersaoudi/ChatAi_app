1. Présentation générale

Codenix est une application web full-stack : frontend Next.js, backend FastAPI. Un utilisateur authentifié (Clerk) dialogue avec un modèle d'IA (Groq), peut joindre un PDF à son message pour des réponses fondées sur le document (RAG), et retrouve son historique persisté.

Fonctionnalités principales

  • Chat temps réel (typewriter), Markdown riche, coloration syntaxique + copie.
  • Envoi combiné PDF + message avec progression 0–100 %.
  • Modes Ask / Agent, sélecteur de modèle, palette Ctrl+K.
  • Thèmes sombre/clair, sidebar redimensionnable, suppression avec confirmation.

4. Architecture détaillée du backend

flowchart TB Client["Client (navigateur)"] MW["Middlewares\nCORS + GZip + lifespan (index)"] Routes["api/routes/\nchat · conversations · rag · health"] Schemas["schemas/ (Pydantic)\nChatRequest, ConversationIn…\n→ 400/422 automatiques"] Services["services/\nai_service : AsyncGroq + fallback + sanitize\nmongo_service : pool 50, ping 30s, index\nrag_service : FAISS + cache mtime"] Prov["Groq · MongoDB · FAISS disque"] Client --> MW --> Routes --> Schemas --> Services --> Prov

main.py ne contient que la fabrique (CORS, GZip, lifespan). Les routes sont fines, les schémas valident, les services portent le métier. Erreurs mappées : 503 (dépendances), 502 (provider avec cause), 500 (filet).

13. Stratégie de versions et montée de version

SemVer strict (MAJEURE.MINEURE.PATCH) : APP_VERSION (frontend) et version FastAPI avancent ensemble ; tout changement visible = entrée Changelog (format Keep a Changelog : Added/Changed/Fixed).

Processus de montée de version des dépendances

  1. Audit : npm outdated / pip list --outdated + npm audit ; Dependabot ouvre déjà les PRs chaque lundi (npm + pip, max 5, CI exigée).
  2. Branche dédiée chore/upgrade-xxx : une famille à la fois (jamais framework + libs ensemble).
  3. Verrous : package-lock.json et versions requirements.txt committés ; pas de latest flottant (leçon : Next 15.3.5 → 15.5.26 épinglé).
  4. Validation : tests (pytest + Vitest + Playwright), next build local, revue Swagger (/docs), déploiement staging si risque.
  5. Montées planifiées :
